Exercício 5

Consultoria Técnica para Criação de Unidades de Conservação (UCs)

Vocês foram contratados pela Secretaria de Meio Ambiente de um estado brasileiro para realizar um diagnóstico da estrutura da paisagem de um município estratégico. O objetivo da consultoria é fundamentar tecnicamente a criação de novas Unidades de Conservação, identificando áreas que possuam características espaciais favoráveis à manutenção da biodiversidade e à integridade dos processos ecológicos.

Município escolhido: Mataraca (PB)

O município de Mataraca está localizado no litoral norte do estado da Paraíba, está a aproximadamente 110 km de distância da capital do estado e a faz fronteira com o estado do Rio Grande do Norte. A área abriga parques eólicos, fragmentos de Mata Atlântica, uma mina desativada, além de possuir regiões de mangue e várzea. Mata Paraibana é a mesorregião em que se insere com o bioma predominante de Mata Atlântica e matriz de cana-de-açúcar.

De acordo com dados do IBGE, a população estimada de 2025 era de 8650 distribuída em um território de 182,439km², o que culmina numa densidade demográfica estimada em 47,41 habitantes por km². Outro dado importante retirado do IBGE, é que em 2022 a cidade possuía uma população indígena de 1000 pessoas, cerca de 12% da população no mesmo ano.

Através do RStudio foi possível abrir o arquivo de raster de cobertura do solo de Mataraca baixado pelo MapBiomas. No software, foi feito o mapa abaixo com as coordenadas em UTM (EPSG:31985) e 14 categorias de uso do solo.

Calculando as métricas

Por meio das métricas diversidade de Shannon, percentual de floresta e densidade de borda é possível compreender a hetogeneidade de cada buffer, mensurar a quantidade de formação florestal nos pontos e quantificar o tamanho da borda para compreender a fragmentação do buffer, respectivamente.

Mostrar código 
# Identificar o valor numérico da classe Floresta
id_floresta <- legenda$id[legenda$Categoria == "Formação Florestal"]

# Lista para armazenar métricas de cada buffer
metricas_lista <- list()

for(i in 1:nrow(buffers)) {
  # Recortar o raster para o buffer i
  crop_i <- crop(r_utmm, buffers[i,])
  mask_i <- mask(crop_i, buffers[i,])
  
  # Calcular Shannon diversity (nível da paisagem)
  shannon <- lsm_l_shdi(mask_i)
  
  # Calcular métricas de classe para todas as classes
  pland_all <- lsm_c_pland(mask_i)   # percentual de cada classe
  ed_all <- lsm_c_ed(mask_i)         # densidade de borda por classe
  
  # Filtrar apenas a classe floresta
  pland_floresta <- pland_all %>% filter(class == id_floresta)
  ed_floresta <- ed_all %>% filter(class == id_floresta)
  
  # Extrair valores (se não houver floresta, colocar NA ou 0)
  div_shannon <- shannon$value
  perc_floresta <- ifelse(nrow(pland_floresta) > 0, pland_floresta$value, 0)
  dens_borda <- ifelse(nrow(ed_floresta) > 0, ed_floresta$value, NA)
  
  # Guardar
  metricas_lista[[i]] <- data.frame(
    id_buffer = i,
    diversidade_shannon = div_shannon,
    perc_floresta = perc_floresta,
    densidade_borda_m_ha = dens_borda
  )
}

# Combinar tudo
metricas_paisagem <- bind_rows(metricas_lista)

print(metricas_paisagem)

Painel de paisagens

Nesse painel, é possível visualizar com maior riqueza de detalhes da cobertura e uso do solo de cada buffer criado.

Mostrar código 
lista_recortes <- list()
for(i in 1:nrow(buffers)) {
  crop_i <- crop(r_utmm, buffers[i, ])
  mask_i <- mask(crop_i, buffers[i, ])
  df_i <- as.data.frame(mask_i, xy = TRUE, cells = TRUE)
  df_i$id_buffer <- paste("Paisagem", i)
  lista_recortes[[i]] <- df_i
}
df_painel <- bind_rows(lista_recortes)

ggplot(df_painel) +
  geom_tile(aes(x = x, y = y, fill = Categoria)) +
  scale_fill_manual(values = setNames(legenda$Cores, legenda$Categoria)) +
  facet_wrap(~id_buffer, nrow = 3, ncol = 5, scales = "free") +
  theme_minimal() +
  labs(title = "Painel de Amostragem: 15 Paisagens de Mataraca-PB",
       subtitle = "Recortes circulares de 500m de raio (Interior de Floresta)",
       fill = "Uso do Solo") +
  theme(axis.text = element_blank(),
        axis.ticks = element_blank(),
        panel.grid = element_blank(),
        legend.position = "bottom")

Observando somente o percentual de cobertura florestal, o buffer com melhor integridade ecológica é o 5 com 42% de formação florestal e 42,9% de densidade de borda. O buffer 8 também apresenta mais de 40% de cobertura florestal, além de possuir a maior heterogeneidade na paisagem, com corpo d’água e campo alagado. Outro buffer importante ser ressaltado nesse sentido é o 14, mais isolado, mas que possui baixa densidade de borda em relação ao percentual de formação florestal (36,95% e 42,51%, respectivamente) comparando com os demais buffers

Existem áreas sim que podem funcionar como conectividade funcional, sendo uma delas nos fragmentos mais próximos da área mais urbanizada de Mataraca, ao sul do município, com uma formação savânica entre o fragmento com os buffers 1, 15, 3 (sendo esse último com pouca cobertura vegetal) e o fragmento com o buffer 2. O próprio buffer 2 pode ser usado como ponto de conexão também com a área dos buffers 12 e 4. Além disso, seguindo mais ao norte do município o buffer 4 pode ser conectado ao fragmento do 6 através do campo alagado que há entre eles, a depender das condições desse campo, da sazonalidade e da espécie em questão. O campo alagado, nesse sentido também pode promover a conectividade entres os buffers 5, 6 e 13. O buffer 13 apresenta baixo percentual de formação florestal e maior parte desse ponto é constituído por campo alagado.

Dessa forma, uma Área de Proteçao Ambiental deve ser criada na região dos buffers de 1 ao 13, incluindo os pontos 15, 3, 2, 12, 4 ,5, e 6.
